# 道の気配MAP｜東広島市（仮称） Viewer Draft 0.1

交通事故データ可視化・現地確認ツール。  
旧「東広島市 交通事故ビューア」からの名称変更案です。名称は未確定です。

## この版の位置づけ
円陣メンバーによる閲覧・画面共有を主用途とする Viewer のたたき台です。
URLがグループ外へ伝わっても機密情報が漏れないよう、**搭載情報は公開情報だけ**とする方針です。

Viewer の役割は「見る・気づく・共有する・話す」です。
解析・候補地選定・内部管理は別系統の Analyst 版で扱います。

## Viewerで残している主な機能
- 個別事故点
- 集計ドーナツ
- 年・事故類型等の絞り込み
- 事故ID検索
- 公開行政・施策参照レイヤー
- 施設参照（試験表示）
- Googleマップ／ストリートビュー連携
- 「この集計をAIが読む」
  - AIへ自動送信せず、共通入力文をクリップボードへコピーします。

## Viewerで表示しない機能
- 機序再現性
- 任意エリア保存・比較
- CSV保存
- 事故ID比較リスト
- Excelコピー
- 候補地選定
- 非公開カーブミラー台帳等の内部データ

## 公開上の前提
- GitHub Pages等でURL共有する場合も、サイト内容は公開され得る前提で運用します。
- `noindex` は検索エンジンへの掲載抑制のための指定であり、アクセス制限ではありません。
- APIキー、パスワード、非公開設備台帳、内部メモ等はこのViewerへ入れません。
- 本リポジトリにOSSライセンスを付与するかは未決定です。公開前に別途判断してください。
