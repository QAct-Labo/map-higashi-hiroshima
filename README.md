# 道の気配MAP｜東広島市（仮称） Viewer v0.6.23

## v0.6.23 の変更

左側パネルの情報構造を整理しました。

### 「表示条件と結果」を1つのグループへ

以下をひとまとまりとして扱います。

- 個別事故点の絞り込み／集計表示項目
- 現在の表示画面に入っている事故件数
- 選択項目の件数
- 構成比グラフ

つまり、

**何を選んだか → その選択で何件になったか → どの程度を占めるか**

までを1つのセルとして読む構成です。

### 「地図の濃さ」を一段下へ

地図の濃さはデータの選択条件ではなく、背景地図の見え方を調整する機能なので、
「表示条件と結果」のグループの下へ移動しました。

これにより、

1. 表示条件を選ぶ
2. 数値と割合を見る
3. 必要に応じて背景地図の濃さを調整する

という順で読めます。
