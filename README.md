# 道の気配MAP｜東広島市（仮称） Viewer v0.6.13

**交通事故データ可視化・現地確認ツール**  
旧「東広島市 交通事故ビューア」からの名称変更案です。名称は現時点では未確定です。

## このViewerについて

この版は、公開情報だけを用いて事故の分布や記録を一緒に「見る・気づく・話す」ための閲覧・共有用Viewerです。

円陣メンバーでの閲覧・画面共有を主用途として想定していますが、URLがグループ外へ伝わっても機密情報が漏れないよう、**Viewerには公開して差し支えない情報だけを搭載する**方針で作成しています。

設計上の考え方は、

> 大事なものを隠し持つのではなく、Viewerには大事なものを携帯させない。

です。

## 主な機能

- 個別事故点表示
- 集計表示（ドーナツ）
- 表示モード切替
  - **個別事故点｜1件ずつ見る**
  - **集計｜まとまりで見る**
- 年・事故類型等による絞り込み
- 事故ID検索
- 公開行政・施策参照レイヤー
- 施設参照
- Googleマップ／ストリートビュー連携
- 表示画面上の事故件数・構成比表示
- 「この集計をAIが読む」
- 多角形による単一範囲集計
- 選択範囲の集計ポップアップ
- 選択範囲の「この範囲をAIが読む」
- 選択した多角形を保持したまま、範囲内の個別事故点だけを表示

## v0.6.13 の主な変更

多角形で囲んだ範囲のポップアップを、既存のエリア集計ポップアップと同じ読み方へ統一しました。

表示項目は、主に以下です。

- 人対車両
- 車両相互
- 車両単独
- 自転車関与
- 交差点内事故
- 無信号事故
- 夜間事故

各項目を **件数＋構成比＋横バー** で表示します。

また、選択範囲のポップアップから **「個別事故点で見る」** を選ぶと、

1. 多角形を保持
2. 地図中心・縮尺を維持
3. 個別事故点モードへ切替
4. 選択した多角形内の事故点だけを表示

します。

これは、異なるモードのポップアップを無制限に同居させるのではなく、**集計で作った「範囲の文脈」を個別表示へ引き継ぐ**ための仕組みです。

## 「AIが読む」について

「この集計をAIが読む」「この範囲をAIが読む」は、AIへ自動送信する機能ではありません。

Viewer内で共通入力文を生成し、クリップボードへコピーします。  
コピーした文章を、利用者自身がお手持ちの生成AIへ貼り付けて使用します。

選択範囲については、主に、

1. 選択範囲で確認できる事実
2. 市全体と比べて目につく構成
3. 次に現地で確認したいこと

を整理するための入力文を作成します。

事故原因、危険度、施策効果をViewerだけで断定する用途ではありません。

## Viewerで意図的に提供しない機能

Viewerは「見る・気づく・共有する・話す」ことに特化しています。

以下は解析用（Analyst）側で扱う想定です。

- 複数範囲の保存・比較
- 事故ID比較リスト
- Excel向けコピー
- CSV／JSON出力
- 候補地点の内部管理
- 高度な解析指標
- 非公開または内部利用のカーブミラー台帳
- PROJECT / RESTRICTED 区分のデータ

## 事故IDについて

Viewer内の「事故ID」は、本Viewer内で事故記録を検索・共有するための管理番号です。

**警察等が使用する公式事故番号ではありません。**

会議や画面共有時に「事故ID 842を見てください」のように、同じ事故記録へ移動するために使用します。

## 参照レイヤーについて

行政・施策参照レイヤーや施設参照は、公開資料をもとにしています。

公表資料に緯度経度が示されていないものについては、Viewer上の位置を **閲覧用代表位置** として表示している場合があります。

そのため、Viewer上の点を行政上の公式座標、施設境界、施策区域そのものとして扱わないでください。

## このViewerで分かること／分からないこと

このViewerは、事故記録の分布、件数、構成、近接関係などを地図上で確認するためのものです。

Viewerだけでは、以下を直接判断できません。

- 事故原因
- 将来の事故発生確率
- その場所の「危険度」
- カーブミラー等の設備効果
- 特定施策の因果的な効果

基本的な使い方は、

> **事故記録から問いを見つけ、現地で確かめる場所を探す。**

です。

## GitHub Pagesでの公開

このViewerは静的HTMLとして動作します。

GitHub Pagesでは、リポジトリ直下に `index.html` を置き、Pagesの公開元を

- Branch：`main`
- Folder：`/(root)`

として公開できます。

既存の共有URLを維持したまま更新する場合は、GitHub上の `index.html` を新しい版へ置き換えてCommitしてください。

## 公開上の前提

- `noindex / nofollow / noarchive` を指定しています。
- これは検索エンジンへの掲載抑制を意図したもので、アクセス制限ではありません。
- URLを知っている人は閲覧できる前提で運用してください。
- APIキー、パスワード、非公開設備台帳、内部メモ等はViewerへ入れません。

## ライセンスについて

このリポジトリをPublicにしても、それだけで第三者へ自由な再利用を許諾することにはなりません。

現時点では、このViewer独自部分についてオープンソースライセンスを設定していません。  
正式公開・自治体展開・第三者への再利用許諾を行う段階で、ライセンス方針を別途決定してください。
