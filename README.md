# 道の気配MAP｜東広島市（仮称） Viewer v0.6.17

**交通事故データ可視化・現地確認ツール**

## v0.6.17 の変更

多角形で「範囲を囲んで集計」したときに開く **選択範囲集計ポップアップ** を、
個別事故点／集計の表示モードを切り替えても閉じない仕様に変更しました。

### なぜ保持できるか

個別事故ポップアップや通常のドーナツ集計ポップアップは、
その表示モード上の事故点・集計セルに紐づいています。
そのためモードを切り替えると、元になった地図記号が消える場合があります。

一方、選択範囲集計ポップアップは **利用者が確定した多角形そのもの** に紐づいています。
多角形はモード切替後も保持されるため、このポップアップだけはモードを跨いで残しても
対応関係が失われません。

### モード切替時の動作

- 選択範囲集計ポップアップ：保持
- 個別事故ポップアップ：閉じる
- 通常のドーナツ集計ポップアップ：閉じる
- 参照地点など、モード依存のポップアップ：従来どおり必要に応じて閉じる

選択範囲ポップアップは、モード切替後に内容・切替ボタン・リーダー線を再同期します。

### リーダー線

件数ラベルはモードごとに、
- 個別事故点を避ける
- 集計ドーナツを避ける

よう位置が変わる可能性があります。

v0.6.17では、モード切替後の再描画が終わってからポップアップの接続先を更新し、
リーダー線を新しい件数ラベル位置へ追従させます。
