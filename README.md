# 道の気配MAP｜東広島市（仮称） Viewer v0.6.14

**交通事故データ可視化・現地確認ツール**  
旧「東広島市 交通事故ビューア」からの名称変更案です。名称は現時点では未確定です。

## このViewerについて

公開情報だけを用いて、事故の分布や記録を一緒に「見る・気づく・話す」ための閲覧・共有用Viewerです。

Viewerは「見る・気づく・共有する・話す」に特化し、解析・保存・複数比較などはAnalyst側で扱う想定です。

## v0.6.14 の変更

### 1. 操作順の変更
「事故IDから探す」と「範囲を囲んで集計」の位置を交換しました。

初見時の流れを、

**表示モードを触る → 範囲を自分で囲って集計する → 見え方・件数を確認する → 必要なら事故IDで特定記録へ移動する**

という探索寄りの順序へ寄せています。

### 2. 「AIが読む」の重複を整理
v0.6.13では、

- 左パネル「範囲を囲んで集計」
- 選択範囲の集計ポップアップ

の両方に「この範囲をAIが読む」がありました。

v0.6.14では、**AI操作を集計結果ポップアップへ集約**しました。

左パネルは、

- 多角形で囲む
- 確定
- 解除
- 集計結果を開く

という「範囲操作」に専念します。

AIで読む場合は、集計結果ポップアップ内の **「この範囲をAIが読む」** を使用します。

これにより、同じ機能が二か所にある迷いを減らしつつ、ポップアップを閉じた後も左側の **「集計結果を開く」** から再表示できます。

## 主な機能

- 個別事故点表示
- 集計表示（ドーナツ）
- 多角形による単一範囲集計
- 選択範囲の集計ポップアップ
- 多角形を保持したまま範囲内の個別事故点へ切替
- 表示画面／選択範囲の件数・構成比
- 事故ID検索
- 公開行政・施策参照レイヤー
- 施設参照
- Googleマップ／ストリートビュー連携
- 「この集計をAIが読む」
- 選択範囲ポップアップ内の「この範囲をAIが読む」

## AI機能について

AIへ自動送信はしません。Viewerが共通入力文を生成し、クリップボードへコピーします。利用者自身がお手持ちの生成AIへ貼り付けて使用します。

## 基本的な読み方

> **事故記録から問いを見つけ、現地で確かめる場所を探す。**

Viewerだけで事故原因、将来の危険率、設備効果、施策の因果効果を断定するものではありません。

## 公開上の前提

- GitHub Pages等で共有可能な公開情報のみを搭載する方針です。
- `noindex / nofollow / noarchive` は検索エンジンへの掲載抑制を意図したもので、アクセス制限ではありません。
- APIキー、パスワード、非公開設備台帳、内部メモ等はViewerへ入れません。
