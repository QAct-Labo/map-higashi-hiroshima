- 推定座標による自動補正は行わない

### 事故ID 707について

現在座標は 34.7737319, 132.6951167。全2,263件中の最近傍事故まで約22.5km、同一路線コードの他事故まで約34.3km離れており、地理妥当性に強い疑義があります。

元データからの座標再計算自体は一致しているため、Viewerの描画バグと断定せず、元データ座標・自治体抽出条件・道路実位置を再確認します。確認が終わるまでは二次解析へ混ぜません。
