# 道の気配MAP｜東広島市（仮称） Viewer v0.6.27

## v0.6.27 の変更

「範囲を囲んで集計」で開いた集計結果ポップアップを、
個別事故点の絞り込み変更をまたいでも保持するようにしました。

### 保持される切替

範囲集計ポップアップを開いたまま、次を切り替えられます。

- すべて
- 人対車両
- 自転車関与
- 車両相互
- 車両単独
- 個別事故点 ↔ 集計

多角形、地図中心、縮尺、範囲集計ポップアップの文脈を維持します。

### ポップアップの扱い

- **範囲集計ポップアップ**：保持
- **個別事故点の通常ポップアップ**：絞り込み変更時には閉じる
- **通常の集計ドーナツのポップアップ**：表示モード等の変更時には従来どおり整理

これにより、範囲全体の集計を基準として見たまま、
個別事故点側の見え方だけを切り替えて比較できます。

範囲集計そのものは、個別事故点の絞り込み条件ではなく、
現在の年条件と選択多角形を基準にした集計です。
